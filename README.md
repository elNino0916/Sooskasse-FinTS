# Sooskasse-FinTS is now Girovo

**This repository is not the project.** Sooskasse-FinTS was renamed to **Girovo**. The source code, issues and every current release are here:

### → [github.com/elNino0916/Girovo](https://github.com/elNino0916/Girovo)

> **Deutsch:** Sooskasse-FinTS heißt jetzt Girovo. Quellcode, Fehlermeldungen und alle aktuellen Versionen findest du unter [github.com/elNino0916/Girovo](https://github.com/elNino0916/Girovo). Hast du Sooskasse-FinTS installiert, musst du nichts tun: Die App findet das Update auf Girovo von selbst.

## Why this repository exists

Sooskasse-FinTS up to version 4.3, and Girovo 5.0.0, look for updates here, under the project's old name. This repository gives them the update to the current Girovo. Once updated, the app looks for updates in the Girovo repository and never comes back here.

If you have one of those versions installed, you don't need to do anything. The app finds the update by itself, at start and every six hours, and shows it under **Sitzung → Updates**.

## What's in it

| Release | What it's for |
|---|---|
| `v5.0.1` (latest) | The update to Girovo. These are the same files as in the Girovo repository. |
| `v5.0.0`, `v4.3.0`, `v4.2.2`, `v4.2.1`, `v4.2.0` | The original installers of those versions, with their blockmaps. An installed copy compares itself with them, so the update downloads only what changed: a few MB instead of about 112 MB. |

Don't install from the older releases here. To install Girovo, use the [latest release in the Girovo repository](https://github.com/elNino0916/Girovo/releases/latest).
